# Research notes

Notes behind every test on testik: what each instrument is, its licence, where the norms come from, and what could not be verified. `SCHEMA.md` is the JSON format used in `src/content/tests/`.

- `mental_health.md`: GAD-7, PHQ-9, PSS-10, burnout, ADHD (ASRS), autism (AQ-10, held back)
- `wellbeing_relationships.md`: life satisfaction, self-esteem, attachment, empathy, emotional intelligence, love languages
- `career_lifestyle.md`: RIASEC, Klimov, values, grit, chronotype, leadership
- `cognitive.md`: IQ (ICAR-style), CRT and the four mini-games
- `personality.md`: Big Five, temperament, Jungian types, HEXACO, dark triad (held back)
- `fun_1.md`: spirit animal, element, archetype, superpower, cosmic object
- `fun_2.md`: dessert, city, weather, drink, dog breed, meme energy

`scripts/quiz-tools/fun1/` and `scripts/quiz-tools/fun2/` rebuild and rebalance the fun quizzes.
